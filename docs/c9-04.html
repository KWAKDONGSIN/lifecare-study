구간 C — 후처리 (13~15단계)

7장에서 배운 두 가지 다듬기예요. 실습에서는 04번과 05번 스크립트예요.

단계도구넣는 것 → 나오는 것왜 하나요
13. PCR 중복 제거picard MarkDuplicates (이후 SortSam)sorted BAM → dedup BAM + metrics 파일PCR 복사본이 변이 비율을 부풀리는 걸 막아요. amplicon 데이터는 생략해요.
14. BQSR (1) 보정표 만들기gatk BaseRecalibratordedup BAM + 레퍼런스 + 알려진 SNP(dbSNP) → recal_data.table알려진 SNP를 정답지로 삼아 품질 점수의 버릇을 계산해요.
15. BQSR (2) 보정 적용gatk ApplyBQSRdedup BAM + 보정표 → final BAM(실습 이름 recal.bam)품질 점수를 다시 써서 에러를 변이로 착각하는 일을 줄여요. 분석 준비 완료(analysis-ready)예요.
시험엔 이렇게 써요

정렬된 BAM에서 Picard MarkDuplicates로 PCR 중복을 제거하고 다시 정렬한 뒤, dbSNP를 정답지로 BaseRecalibrator가 재보정 테이블을 만들고 ApplyBQSR가 품질 점수를 다시 써서 final BAM을 만든다.

잠깐 확인 — 후처리가 끝나면 어떤 BAM이 나오나요?

분석 준비 완료 BAM(analysis-ready BAM, final BAM)이에요. 실습 스크립트에서는 recal.bam이라고 불러요.
