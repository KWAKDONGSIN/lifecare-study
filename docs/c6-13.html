리눅스 — 딱 이것만

교수님이 "명령어 세부는 디테일이라 안 본다"고 하셨어요. 개념만 알면 돼요.

왜 리눅스?

생물정보 분석 도구들이 수십 년간 오픈소스(무료·공개)인 리눅스 위에서 만들어져 쌓였기 때문이에요. 교수님 표현으로 "선택이 아니라 하려면 리눅스에서 할 수밖에 없는" 상황이에요.

  • 커널(kernel) = 운영체제의 핵심으로 메모리 같은 하드웨어를 관리해요. 셸(shell) = 껍데기, 우리가 친 명령어를 해석해 커널에 전달해요. 이 수업은 셸 중 bash를 써요.
  • 셸 스크립트 = 명령어를 여러 줄 모아 둔 파일이에요. 첫 줄에 #!/bin/bash를 적어요.
  • 가상환경(conda) = 도구마다 필요한 버전이 달라 서로 꼬이니까, 목적별로 작은 방을 따로 만들고 필요한 도구만 깔아 두는 것이에요.
비유

식당에서 주방이 커널이라면, 주문을 받아 주방에 전달하는 홀 직원이 셸이에요. 손님(우리)은 직원에게만 말하면 돼요. 가상환경은 요리마다 쓰는 전용 주방 칸이라고 생각하세요.

파일 권한은 읽기·쓰기·실행을 숫자로 적어요. r(읽기)=4, w(쓰기)=2, x(실행)=1이에요.

  • ls -al로 보면 -rw-r--r--처럼 나와요. 맨 앞 글자는 파일(-)인지 폴더(d)인지이고, 나머지 9글자는 user(주인) / group(모둠) / other(남들) 세 칸씩이에요.
  • rw- = 4+2 = 6, r-- = 4이니 -rw-r--r--는 644예요.
  • chmod 755 = 나는 전부(4+2+1=7), 나머지는 읽기와 실행(4+1=5). 777 = 모두에게 전부 허용.

그 밖에 두 가지만 더 알아 두세요.

  • 리다이렉션 — 결과를 화면 대신 파일에 저장해요. >는 덮어쓰기, >>는 이어쓰기, 2>는 에러만 저장이에요.
  • 파이프 | — 앞 명령의 출력을 뒤 명령의 입력으로 넘겨요(앞에서 본 컨베이어 벨트).
시험엔 이렇게 써요

생물정보 분석 도구는 오픈소스인 리눅스 환경에서 수십 년간 발전해 왔기 때문에 리눅스 사용이 필수다. 도구마다 버전이 달라 충돌하므로 가상환경(conda)을 만들어 목적별로 분리하고, 파일 권한은 r=4, w=2, x=1의 합으로 나타낸다.

잠깐 확인 — 권한 rwxr-xr-x를 숫자로 쓰면?

755예요. rwx = 4+2+1 = 7, r-x = 4+1 = 5, r-x = 5이기 때문이에요.
