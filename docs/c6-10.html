SAM 한 줄에 적힌 것 — 11칸

SAM 파일에서 조각 하나는 한 줄이고, 그 줄은 11칸으로 이루어져 있어요. 다 외울 필요는 없고 굵은 글씨만 기억하세요.

칸뜻
1. QNAME조각 이름
2. FLAG상태 번호. 0 = 정방향(forward)으로 붙음, 16 = 역방향(reverse)으로 붙음, 4 = 못 붙음(unmapped)
3. RNAME어느 레퍼런스(염색체)에 붙었나
4. POS몇 번째 자리부터 붙었나 (시작 위치)
5. MAPQ제자리 확신도. 60 = 잘 붙음(확실)
6. CIGAR어떻게 붙었나 (다음 소단원)
7~9. RNEXT · PNEXT · TLEN짝꿍 조각 정보(페어드엔드)
10. SEQ조각의 글자(서열)
11. QUAL글자별 품질 점수

아래는 설명용으로 만든 한 줄 예시예요. 짝이 없는 조각은 7~9칸을 * 0 0으로 적어요.

read1 0 chr1 5 60 3M1I3M1D5M * 0 0 ACTAGAATGGCT IIIIIIIIIIII

읽는 법은 이래요. "read1은 정방향(0)으로 chr1의 5번 자리부터 붙었고, 확신도 60, 붙은 모양은 3M1I3M1D5M이다."

MAPQ 60은 위치가 틀렸을 확률이 약 10의 -6승(백만 번에 한 번)이라는 뜻이에요. 점수가 높을수록 믿을 만해요.

FLAG는 숫자 하나에 여러 정보를 더해서 담아서 147 같은 큰 값도 나와요. 시험에서는 0, 16, 4만 알면 돼요.

외우기 팁

FLAG 0 = 앞으로(정방향) · 16 = 뒤집어서(역방향) · 4 = 못 붙음. POS = 시작 번호, MAPQ = 60이면 OK.

잠깐 확인 — FLAG가 4인 조각은 어떤 상태일까요?

레퍼런스에 붙지 못한 조각(unmapped)이에요. 0은 정방향, 16은 역방향으로 붙은 경우예요.
