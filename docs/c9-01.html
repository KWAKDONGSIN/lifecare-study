실습 전체 지도

교수님은 개념을 모르면 실습할 때 지금 무슨 스텝인지 모른다고 여러 번 말했어요. 그래서 이 장은 실습을 "단계"로 나눠서 보여 줘요. 아래 번호는 이 책에서 편의상 붙인 단계 번호이고, 시험에 번호가 나오지는 않아요.

비유

요리 순서와 같아요. 재료 손질(품질 검사·트리밍) → 위치 맞춰 담기(정렬) → 불순물 거르기(중복 제거·BQSR) → 맛 보며 골라내기(변이 호출·필터) → 의미 적기(annotation)로 이어져요.

구간단계 번호하는 일
A. 준비와 점검0~5환경 준비, FASTQ 받기, 품질 검사, 어댑터 자르기, 합치기, BLAST 구경
B. 정렬6~12read를 레퍼런스 위치에 맞추고 숫자와 눈으로 점검
C. 후처리13~15PCR 중복 제거, BQSR (7장)
D. 변이 호출과 필터16~19HaplotypeCaller, GenotypeGVCFs, 하드 필터 (7장)
E. Annotation20~22ANNOVAR로 의미 붙이기 (8장)

변이 호출 실습은 번호가 붙은 스크립트를 순서대로 돌렸어요. 02번 품질 검사·트리밍, 03번 정렬, 04번 후처리(MarkDuplicates), 05번 BQSR, 06번 변이 호출, 07번 하드 필터예요. 번호가 곧 순서예요.

실습은 모두 리눅스 서버에서 했어요. 도구가 설치된 가상환경(conda)에 들어간 뒤, 내 폴더로 이동해서 스크립트를 돌렸어요. 결과 BAM·BAI는 WinSCP로 내 PC에 옮겨서 웹 IGV에 올려 봤어요.

시험엔 이렇게 써요

변이 분석 파이프라인은 FASTQ를 QC·트리밍한 뒤 BWA로 정렬해 sorted BAM과 index를 만들고, MarkDuplicates와 BQSR로 후처리한 후 HaplotypeCaller(GVCF)와 GenotypeGVCFs(VCF), 하드 필터를 거쳐 ANNOVAR로 annotation하는 순서이다.

잠깐 확인 — 실습에서 07번 스크립트는 파이프라인의 어디인가요?

하드 필터 단계예요. 06번 변이 호출 다음에 기준 미달 변이를 버려요.
