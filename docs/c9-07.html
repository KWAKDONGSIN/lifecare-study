파일 이름이 어떻게 바뀌나요

단계마다 파일의 이름과 모양이 바뀌어요. 이것만 알아도 파이프라인이 머릿속에 그려져요.

단계나오는 파일
시퀀서FASTQ (.fastq, .fq.gz) — R1, R2 두 개
정렬 직후SAM(텍스트) → BAM(이진) → sorted BAM + .bai
레퍼런스 쪽FASTA (.fa)와 그 인덱스
MarkDuplicatesdedup.bam + metrics 파일
BQSRrecal_data.table → 최종 BAM (final 또는 recal)
HaplotypeCaller.g.vcf (GVCF)
GenotypeGVCFs.vcf → 하드 필터 후 FILTER 칸이 채워짐
ANNOVAR.avinput → annotation 표

교수님은 분석 준비가 끝난 지점을 ".bam까지 오면 이후 결과 확장자는 VCF"라고 정리했어요. BAM까지는 정렬과 후처리, 그 뒤로는 변이 파일이라는 뜻이에요.

시험엔 이렇게 써요

시퀀서가 FASTQ를 만들고, 정렬하면 SAM이 나오며 이를 BAM으로 바꿔 sort하고 .bai 인덱스를 만든다. 변이 호출 후에는 GVCF와 VCF가 나온다.

잠깐 확인 — 정렬된 BAM의 인덱스 파일 확장자는?

.bai예요. 단답형으로 나온 적이 있어요.
