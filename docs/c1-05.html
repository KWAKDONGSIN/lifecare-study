⑥~⑧ 제자리에 붙이고 정리하기

⑥ 얼라인먼트(alignment, 정렬)예요. 쪽지 수억 장이 정답지(레퍼런스)의 어디에서 왔는지 찾아 붙이는 일이에요. 교수님은 "퍼즐 조각 맞추기"라고 했어요.

도구는 BWA(Burrows-Wheeler Aligner)예요. 결과는 먼저 글자 파일인 SAM(Sequence Alignment/Map)으로 나오고, 같은 내용을 컴퓨터가 빨리 읽게 압축한 것이 BAM이에요. 그다음 위치 순서로 줄을 세우고(sort) 찾아보기용 번호표(index, BAI)를 만들어요.

⑦ MarkDuplicates(마크 듀플리케이츠)예요. 도구는 Picard예요. 준비 과정에서 같은 조각이 PCR(Polymerase Chain Reaction, DNA 복사 기술)로 여러 번 복사될 수 있는데, 이 복사본이 변이 비율을 부풀려요. 그래서 복사본을 표시하고 빼요.

⑧ BQSR(Base Quality Score Recalibration, 염기 품질 점수 재보정)예요. 도구는 GATK(Genome Analysis Toolkit)예요. 기계가 붙인 품질 점수에는 습관적인 치우침이 있어서, 이미 알려진 변이 목록(SNP 데이터베이스)을 기준으로 점수를 다시 맞춰요. 기계의 읽기 실수를 변이로 착각하지 않으려는 거예요.

비유

정렬은 찢어진 쪽지를 표준 책 위에 올려 제자리에 붙이는 일이에요. MarkDuplicates는 같은 쪽지를 복사기로 여러 장 뽑았을 때 한 장만 남기는 일이에요. BQSR은 체중계가 늘 1kg 많게 나오면 영점을 다시 맞추는 일이에요.

외우기 팁

⑥~⑧에서 도구 이름은 BWA(붙이기) → Picard(복사본 빼기) → GATK(점수 보정) 순서로 외우세요. 한 단계씩 "왜 하는지"를 같이 말할 수 있으면 돼요.

시험엔 이렇게 써요

BWA로 read를 레퍼런스에 정렬해 SAM을 만들고 BAM으로 변환한 뒤 위치순으로 정렬하고 인덱스를 만든다. Picard MarkDuplicates로 PCR 중복 read를 제거하고, GATK BQSR로 염기 품질 점수를 재보정해 시퀀싱 에러가 변이로 오인되는 것을 막는다.

잠깐 확인 — MarkDuplicates는 왜 필요한가요?

PCR로 복사된 같은 조각이 여러 번 세어지면 변이 비율이 부풀려지기 때문에, 중복 복사본을 빼려고 해요.
