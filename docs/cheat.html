헷갈리는 숫자

녹취와 슬라이드가 다르게 말한 숫자 — 시험엔 슬라이드 기준으로

말로 하다 보면 숫자가 틀리기도 해요. 시험 답안에는 슬라이드 숫자를 쓰세요.
· 게놈 크기 — 녹취 "3조" → 슬라이드 30억(3 billion)
· 휴먼 게놈 프로젝트 — 녹취 "3조 달러·300만 달러·15년" → 슬라이드 13년, 30억 달러
· Phred — 녹취 중 "1/100이면 Q30"이라고 한 부분이 있지만 → 슬라이드 1/100 = Q20, 1/1,000 = Q30
· MAPQ 60 — 녹취 "10의 60분의 1" → 공식대로 에러 10⁻⁶
· 스팟 크기 — 녹취 약 1μm → 슬라이드 7μm × 7μm
· 세포 수 — 슬라이드 안에서도 37조(12쪽)와 30조(56쪽 요약)가 둘 다 나와요. 약 30조로 쓰면 안전해요
· 적혈구 비율 — 녹취 83%, 슬라이드 84%. "약 80% 이상이 적혈구"로 쓰면 돼요

같은 말이 두 뜻으로 쓰인 것 — coverage, 트리밍 도구

Coverage — 3주차 슬라이드 25쪽은 "12.5배"처럼 몇 번 덮었나(=depth 개념)로 썼고, 6주차부터는 전체 중 읽힌 비율(90%)로 정의했어요. 서술형에선 6주차 정의(depth = 한 자리를 몇 번, coverage = 전체 중 몇 %)로 쓰세요.
트리밍 도구 — 수업은 cutadapt, 변이 실습 스크립트는 fastp를 썼어요. 둘 다 "어댑터·저품질 자르기"라는 목적은 같아요.
WGS·WES depth — 그림은 30x / 50~100x / 500x 이상, 같은 쪽 표엔 30~60x / 100~150x. 그림 숫자로 외우세요.

시험장에서 — 마지막 1장

✍️ 서술형 쓰는 공식

정의 → 왜(목적) → 예시·숫자

예) "Depth는 한 자리를 몇 개 read가 읽었는지다(정의). 높을수록 에러와 진짜 변이를 구별할 수 있다(왜). WGS는 30x, 암 조기진단은 3000x까지 올린다(숫자)."

🎯 시험지 받자마자
  1. 여백에 1장 파이프라인을 먼저 그려 두기
    FASTQ → QC → 트리밍 → BWA → BAM → MarkDup → BQSR → HaplotypeCaller → VCF → ANNOVAR
  2. 약어 문제는 아는 것부터 빠르게
  3. 모르는 서술형도 빈칸으로 두지 말고 정의 한 줄 + "목적에 따라 판단한다" 같은 교수님 문장이라도 쓰기
🗣 어디에 붙여도 점수 되는 교수님 문장
  • "틀린 그림 찾기는 쉽고, 진짜 변이인지 확률을 계산하는 게 중요하다."
  • "depth가 높을수록 변이 판정이 정확하다."
  • "목적에 따라 파이프라인 단계를 선택한다."
  • "기술 혁신은 비용과 연결된다."
  • "단계마다 IGV와 coverage·depth로 확인한다."
