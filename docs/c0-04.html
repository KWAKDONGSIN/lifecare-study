염기 A, T, G, C — 글자는 딱 4개

책에는 글자가 있죠. DNA의 글자는 딱 4개뿐이고 이것을 염기(base)라고 불러요. 이름은 A, T, G, C예요.

  • A 아데닌
  • T 티민
  • G 구아닌
  • C 사이토신

한글에는 자음·모음이 수십 개인데, DNA는 4글자만으로 사람 한 명을 만드는 책을 써요. 4글자를 아주 길게 배열해서 모든 정보를 담는 거예요.

DNA는 두 가닥이라서 글자끼리 짝을 지어요. 짝은 정해져 있어요.

짝연결(수소결합) 개수느낌
A - T2개살짝 붙음
G - C3개더 단단히 붙음
외우기 팁

"A는 T와, G는 C와" 짝이에요. 그리고 G-C는 손을 3번 잡아서 더 단단해요(G-C가 3개, A-T가 2개).

비유

두 가닥은 지퍼의 양쪽 이빨이에요. A 이빨은 T 이빨하고만, G 이빨은 C 이빨하고만 맞물려요. 그래서 한쪽 가닥을 알면 반대쪽 가닥도 알 수 있어요.

시험엔 이렇게 써요

DNA는 염기 A, T, G, C로 이루어져 있고, A는 T와, G는 C와 상보적으로 짝을 짓는다. G-C는 수소결합이 3개, A-T는 2개여서 G-C 쌍이 더 안정적이다.

잠깐 확인 — A의 짝은 무엇이고, 어느 쪽(A-T, G-C)이 더 단단한가요?

A의 짝은 T예요. 더 단단한 쪽은 G-C예요(수소결합 3개).
