구간 E — Annotation (20~22단계)

8장에서 배운 ANNOVAR 순서 그대로예요. 다만 실습에서는 시간이 오래 걸려 이론으로만 다뤘어요.

단계도구넣는 것 → 나오는 것왜 하나요
20. DB 내려받기annotate_variation.pl -downdb(없음) → humandb 폴더의 DB 파일쓸 DB를 먼저 받아 두어야 annotation을 할 수 있어요.
21. VCF를 avinput으로convert2annovar.plVCF → .avinput(탭 구분 텍스트)ANNOVAR가 읽기 쉬운 형식으로 바꿔요. --vcfinput으로 바로 넣을 수도 있어요.
22. Annotationtable_annovar.plVCF(또는 avinput) + humandb → annotation 표찾은 변이가 무슨 의미인지 DB와 연결해요.
시험엔 이렇게 써요

ANNOVAR를 쓰려면 먼저 필요한 DB를 내려받고, VCF를 avinput으로 변환한 뒤 table_annovar로 annotation하여 변이의 위치와 질병 관련성 등을 얻는다.

잠깐 확인 — annotation을 하기 전에 가장 먼저 해야 하는 일은?

쓸 DB를 먼저 내려받는 것이에요. DB가 없으면 변이를 찾아볼 사전이 없어요.
