외우기 팁

파일 이름 세 개만 먼저 외우세요. FASTQ → BAM → VCF 순서예요.

FASTQ는 "읽은 결과", BAM은 "제자리에 붙인 결과", VCF는 "찾은 변이 목록"이에요.

시험엔 이렇게 써요

FASTQ에서 VCF까지의 분석 순서는 QC, 트리밍과 머지, 얼라인먼트(BAM 생성), MarkDuplicates, BQSR, variant calling, annotation이다. 앞의 FASTQ에서 BAM까지를 pre-processing, BAM에서 VCF까지를 variant discovery라고 한다.

잠깐 확인 — 파일 이름 세 개를 순서대로 말해 보세요.

FASTQ(읽은 결과) → BAM(제자리에 붙인 결과) → VCF(찾은 변이 목록)예요.
