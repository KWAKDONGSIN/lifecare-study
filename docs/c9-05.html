구간 D — 변이 호출과 필터 (16~19단계)

드디어 변이를 찾는 단계예요. 실습에서는 06번과 07번 스크립트예요.

단계도구넣는 것 → 나오는 것왜 하나요
16. 변이 호출gatk HaplotypeCaller (-ERC GVCF)final BAM + 레퍼런스 + 분석 영역(-L) → GVCF(.g.vcf)active region과 haplotype 확률로 진짜 변이일 가능성이 높은 것을 찾아요. 모르는 위치도 NON_REF로 기록해요.
17. Genotype 부여gatk GenotypeGVCFsGVCF → VCF(raw, 확실한 변이만)GVCF에서 최종 genotype(GT)을 붙여 변이만 추려요.
18. SNP와 INDEL 분리gatk SelectVariantsraw VCF → SNP VCF, INDEL VCF종류별로 다른 필터를 쓰려고 나눠요.
19. 하드 필터gatk VariantFiltration (QD, FS, MQ 등) + bcftools view -f PASSSNP VCF → FILTER 칸이 채워진 VCF, PASS만 모은 VCF기준 미달 변이를 버려요. 통과하면 PASS, 못 통과하면 걸린 필터 이름이 찍혀요. 희귀 변이 탐색에서는 생략하기도 해요.
외우기 팁

변이 호출은 "GVCF 먼저 → VCF 추리기 → 필터"의 3박자예요. HaplotypeCaller(GVCF) → GenotypeGVCFs(VCF) → 하드 필터(PASS)로 외우세요.

시험엔 이렇게 써요

GATK HaplotypeCaller로 final BAM에서 GVCF를 만들고, GenotypeGVCFs로 genotype을 붙인 VCF를 추린 뒤, 하드 필터로 기준 미달 변이를 제거해 PASS인 변이만 남긴다.

잠깐 확인 — SNP와 INDEL을 왜 따로 나눠서 필터링하나요?

종류별로 다른 필터 기준을 적용하기 위해서예요. 그래서 SelectVariants로 먼저 나눠요.
